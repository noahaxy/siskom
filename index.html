Materi Pembelajaran

Arsitektur Von Neumann

Komputer modern menyimpan program dan data di memori yang sama. Empat bagian utamanya: unit input, unit pemroses (CPU), memori, dan unit output.

⌨️ Input➜🧠 CPU + 💾 Memori➜🖥️ Output

Perangkat Input – Process – Output

Alur data saat aplikasi berjalan

  1. Input: pengguna memasukkan data lewat perangkat input.
  2. Dimuat: program dan data dipindah dari SSD/HDD ke RAM.
  3. Eksekusi: CPU (dibantu GPU) mengolah instruksi.
  4. Output: hasil ditampilkan atau dicetak.

RAM vs penyimpanan

RAM adalah memori kerja sementara yang cepat, menentukan berapa aplikasi bisa berjalan bersamaan. SSD/HDD menyimpan data permanen; SSD jauh lebih cepat dari HDD.

Memilih komputer yang sesuai

  • Prosesor: kemampuan olah data dan generasinya.
  • RAM: kelancaran multitugas.
  • Penyimpanan: kapasitas dan kecepatan (SSD vs HDD).
  • Grafis: game 3D dan desain butuh GPU dedicated; kerja kantor cukup grafis terintegrasi.
  • Harga: sesuaikan anggaran, kompatibilitas aplikasi, dan kelengkapan perangkat.

Spesifikasi tertinggi belum tentu pilihan terbaik. Nilai kecocokan dengan kebutuhan dan anggaran.
